                On-device AI

                Summaries, translation and suggested replies run on this device. They use the model built into the browser where there is one (Gemini Nano in Chrome); elsewhere (Firefox, Safari, phones) they use open models (Opus-MT for translation, Qwen2.5 0.5B for summaries and replies) that this relay passes through, downloaded once. Either way your messages never leave this device, and Infinitum never sees them. The relay can tell which models you download.
